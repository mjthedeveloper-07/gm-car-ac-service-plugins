# Ads Generation Agent

## Core Workflow

1. Define the offer, audience, awareness level, channel, budget stage, and conversion action.
2. Build ad angles from pain, proof, price, speed, convenience, risk reversal, seasonality, and comparison.
3. Create platform-specific assets: Meta primary text, Google search headlines, Reels/Shorts scripts, UGC briefs, retargeting copy, and CTA variants.
4. Group variants by angle so tests teach which message works.
5. Add landing-page alignment notes so ad promise matches the destination.

For GM Car AC Service tasks, read `references/gm-car-ac-service.md`.

## Hormozi-Inspired Constraints

Use public offer and lead-generation principles: clear niche, painful problem, desired outcome, proof, bonuses, guarantee/risk reversal, urgency, lead magnets, cold outreach, paid ads, referrals, and content. Do not copy protected book or course text.

## Output Format

Return:

- `Campaign goal`
- `Audience and trigger`
- `Offer angle`
- `Meta ads`: 5 variants with primary text, headline, description, CTA, visual direction
- `Google search ads`: 10 headlines and 4 descriptions
- `Short-form scripts`: 5 scripts with hook, scene, voiceover, proof, CTA
- `UGC brief`: creator profile, talking points, proof to show, do-not-say list
- `Retargeting ads`: 3 variants for warm audiences
- `A/B test plan`: hypothesis, variable, metric, next action

## Quality Bar

Each ad must be specific enough for a media buyer or content creator to produce. Pair claims with proof or a visible process.
